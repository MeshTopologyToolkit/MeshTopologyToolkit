# FBX samples

The files in this folder are test data from the [ufbx](https://github.com/ufbx/ufbx) project
(`data` directory), used under its MIT / public domain license.
The `.obj` files are reference exports of the same scenes at the given animation frame
(`*_15.obj` is the pose at frame 15, `*_5.obj` at frame 5, and so on).
